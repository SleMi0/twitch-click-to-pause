# Twitch Click to Pause

[Русский](README.md) | [English](README.en.md)

Chrome-расширение, позволяющее ставить трансляции и видео на Twitch на паузу кликом по плееру, а также возобновлять воспроизведение повторным кликом.

![Иконка расширения](icons/icon128.png)

## Возможности

- Клик по области видео — пауза/возобновление
- Работает на прямых эфирах, VOD и клипах Twitch
- Не мешает работе панели управления, чата, настроек, seekbar и меню
- Работает во встроенных плеерах `player.twitch.tv`
- Переживает SPA-переходы между каналами без перезагрузки страницы
- Минимальный размер, без разрешений, без сетевых запросов

## Как это работает

Расширение вешает один делегированный обработчик клика в фазе capture на `document`. При клике оно:

1. Определяет, попал ли клик по видимому `<video>`.
2. Проверяет, что клик не по кнопкам, ссылкам, контролам, seekbar, меню и другим интерактивным элементам.
3. Переключает воспроизведение через **нативную кнопку** Twitch `player-play-pause-button`, чтобы сохранить корректное состояние плеера.
4. Гасит всплытие события, чтобы на VOD не сработал двойной toggle.

## Установка

### Вариант 1. Скачать с Releases (самый простой)
1. Перейдите на [страницу релизов](https://github.com/SleMi0/twitch-click-to-pause/releases)
2. Скачайте ZIP-архив последнего релиза (например, `twitch-click-to-pause-v1.0.0.zip`)
3. Распакуйте архив в отдельную папку
4. Откройте `chrome://extensions/`
5. Включите **Режим разработчика** (переключатель в правом верхнем углу)
6. Нажмите **Загрузить распакованное расширение**
7. Выберите распакованную папку

### Вариант 2. Установка из исходников
1. Скачайте или клонируйте репозиторий:
   ```bash
   git clone https://github.com/SleMi0/twitch-click-to-pause.git
   ```
2. Откройте `chrome://extensions/`
3. Включите **Режим разработчика** (переключатель в правом верхнем углу)
4. Нажмите **Загрузить распакованное расширение**
5. Выберите папку `twitch-click-to-pause`

Готово. Расширение начнёт работать сразу на всех страницах `*.twitch.tv`.

## Ограничения

- **Live-трансляции.** Twitch не поддерживает timeshift для прямых эфиров. При паузе картинка замораживается, но поток продолжает идти в реальном времени. При возобновлении воспроизведение начнётся с текущего live-момента, а не с того, на котором вы поставили паузу.
- **VOD и клипы.** Пауза и возобновление работают с того же места воспроизведения.
- **Реклама.** Расширение не перехватывает клики во время показа рекламы.
- **Сторонние плееры.** Работает только там, где присутствует стандартный плеер Twitch.
