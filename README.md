# Twitch Click to Pause

[Русский](README.md) | [English](README.en.md)

Chrome-расширение, позволяющее ставить трансляции и видео на Twitch на паузу кликом по плееру, а также возобновлять воспроизведение повторным кликом.

![Иконка расширения](icons/icon128.png)

## Возможности

- Клик по области видео — пауза/возобновление
- Двойной клик — вход и выход из полноэкранного/театрального режима, как в самом Twitch (без паузы)
- Работает на прямых эфирах, VOD и клипах Twitch
- Работает поверх оверлеев расширений Twitch: клики по неинтерактивному фону оверлея проходят к плееру, а клики по элементам управления расширения не пересылаются и остаются за расширением
- Не мешает работе панели управления, чата, настроек, seekbar и меню
- Работает во встроенных плеерах `player.twitch.tv`
- Переживает SPA-переходы между каналами без перезагрузки страницы
- Минимальный размер, без разрешений, без сетевых запросов

## Как это работает

Расширение вешает делегированные обработчики кликов в фазе capture на `document`. При клике оно:

1. Определяет, попал ли клик по видимому `<video>`.
2. Пропускает клики по кнопкам, ссылкам, контролам, seekbar, меню и другим интерактивным элементам. Большая кнопка «Воспроизведение» поверх приостановленного видео считается частью плеера.
3. Ждёт 400 мс, чтобы отличить одиночный клик от двойного. Если за это время пользователь нажмёт контрол, клавишу, откроет меню или модальное окно, отложенный клик отменяется: новое действие имеет приоритет.
4. Одиночный клик — переключает воспроизведение через **нативную кнопку** Twitch `player-play-pause-button`, чтобы сохранить корректное состояние плеера. Отложенное состояние хранится отдельно для каждого видео: клик по одному плееру не отменяет клик по другому.
5. Двойной клик — отменяет паузу и переключает полноэкранный/театральный режим Twitch (вход и выход), поэтому видео не встаёт на паузу при переходе в фуллскрин. Если нативная кнопка недоступна или «проглотила» клик, используется Fullscreen API; `Esc` отменяет отложенный fallback. Восстановление состояния воспроизведения учитывает асинхронное обновление `video.paused`.
6. Гасит всплытие события, чтобы Twitch не выполнил то же действие второй раз.

Оверлеи расширений Twitch (`*.ext-twitch.tv`) открываются в отдельном кросс-доменном iframe, и клики внутри него не доходят до страницы с плеером. Такой iframe пересылает клик родительской странице через `postMessage` (вложенные кадры передают его дальше по цепочке) только тогда, когда клик пришёлся по неинтерактивному фону оверлея. Клики по кнопкам, ссылкам, `canvas`, карточкам и другим интерактивным элементам не пересылаются; они также отменяют отложенный клик в плеере. Родитель проверяет `origin`/`source`, координаты и `detail` сообщения, а затем — что точка действительно лежит над видео. Разработчик расширения может пометить контейнер атрибутом `data-twitch-click-to-pause-ignore`, чтобы исключить его из pass-through.

## Установка

### Вариант 1. Скачать с Releases (самый простой)
1. Перейдите на [страницу релизов](https://github.com/SleMi0/twitch-click-to-pause/releases)
2. Скачайте ZIP-архив последнего релиза (например, `twitch-click-to-pause-v1.1.1.zip`)
3. Распакуйте архив в отдельную папку
4. Откройте `chrome://extensions/`
5. Включите **Режим разработчика** (переключатель в правом верхнем углу)
6. Нажмите **Загрузить распакованное расширение**
7. Выберите распакованную папку

### Вариант 2. Установка из исходников
1. Скачайте или клонируйте репозиторий:
   ```bash
   git clone https://github.com/SleMi0/twitch-click-to-pause.git
   ```
2. Откройте `chrome://extensions/`
3. Включите **Режим разработчика** (переключатель в правом верхнем углу)
4. Нажмите **Загрузить распакованное расширение**
5. Выберите папку `twitch-click-to-pause`

Готово. Расширение начнёт работать сразу на всех страницах `*.twitch.tv`.

## Ограничения

- **Live-трансляции.** Twitch не поддерживает timeshift для прямых эфиров. При паузе картинка замораживается, но поток продолжает идти в реальном времени. При возобновлении воспроизведение начнётся с текущего live-момента, а не с того, на котором вы поставили паузу.
- **VOD и клипы.** Пауза и возобновление работают с того же места воспроизведения.
- **Реклама.** Детект рекламы best-effort: если видимый ad-элемент пересекает видео, клики по всей поверхности видео временно блокируются. Если Twitch изменит разметку рекламы, возможен пропуск.
- **Оверлеи расширений.** Pass-through работает только для неинтерактивного фона. Полноэкранные игры, `canvas`-виджеты и карточки с собственными обработчиками кликов, как правило, не переключают поток. Если игра реализована как обычный `div` без `role`/`cursor`/`tabindex`, эвристика может принять её за фон.
- **Несколько плееров.** Если у кликнутого плеера нет нативной кнопки или она disabled, используется `video.play()`/`video.pause()`. Кнопка другого плеера на странице не нажимается.
- **Fullscreen/theater.** Двойной клик переключает полноэкранный режим Twitch; повторный двойной клик выходит из него в предыдущий layout (обычно с чатом). Если Fullscreen API недоступен, Twitch может использовать theater/full-window; конкретный режим зависит от браузера/окружения. Для оверлеев расширений дублирующий synthetic `dblclick` супервизора подавляется, чтобы выход не попадал в театр без чата. Выход также доступен по `Esc` или штатной кнопке.
- **Сторонние плееры.** Работает только там, где присутствует стандартный плеер Twitch.
